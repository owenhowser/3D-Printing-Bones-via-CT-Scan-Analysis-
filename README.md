# 3D-Printing-Bones-via-CT-Scan-Analysis-
CT scans take images and stack them to build an organ or bone. This program takes these images, looks data from the image to rebuild and smooth out bones in order to be taken, and 3D printed with. 



This uses MatLab. In order to fully use the program, the ImageProcessing Toolbox is needed. MatLab base cannot read .dcm files.
